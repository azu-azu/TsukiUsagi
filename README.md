## TsukiUsagi 🐇
**Personal Portfolio & WordPress Custom Theme**

**URL:** [https://tsukiusagi.biz](https://tsukiusagi.biz)
**Author:** Azu
**Tech Stack:** WordPress, PHP, SCSS (Dart Sass), Gulp, JS

---

### 🌙 Overview
**TsukiUsagi** is my personal portfolio site, designed and developed entirely from scratch.
It represents the theme of *quiet light in the cosmos* — a poetic metaphor for calm technology and gentle presence.

From WordPress theme structure to plugin design, every line of code was written with a focus on **clarity, structure, and emotional tone**.

✨ **Note:** This repository includes only the theme directory (tsukiusagi/) under wp-content/themes/.

---

### 🚀 Tech Stack
- **WordPress** – Custom theme with post types and fields
- **SCSS / Dart Sass** – FLOCSS architecture, modular hierarchy
- **Gulp** – Automated build workflow (minify, compress, SVG sprite, EJS, live reload)
- **JavaScript** – Minimal use for animation
- **Original Plugins** – Created to extend admin functionality and content management

---

### 🔌 Original Plugins
- Auto thumbnail by category
- Text field control from post editor

---

### 🧩 Theme & Frontend Features
- **Theme Architecture**
  - Organized `functions.php` split into logical sections (`setting`, `manage`)
  - Modular plugin system for reusable admin logic
  - Custom pagination & breadcrumb
- **Frontend**
  - Custom Gutenberg blocks
  - CSS-based curtain animation with scroll logic
  - Optimized loading for smooth transitions
  - Optimized frontend workflow with Gulp
- **Development**
  - Clean `.gitignore` with selective version control of only essential files

---

### 🧠 Design Philosophy
- **Structure over speed** — clarity before cleverness
- **Worldview over technique** — design serves atmosphere
- **Logic ≠ Presentation** — separate layers, ensure clarity
- **CSS before JS** — express emotion through motion

---

### 📁 Project Structure

```plaintext
components/        // Template parts
css/               // Compiled CSS files
customizer/        // Theme Customizer settings and sanitizers
js/                // Theme-specific JS modules
plug_in/           // Original admin utility plugins
*.php              // WordPress template files
```
